# FEE

생활비 통장 형태의 가계부. 2026/11/13~12/31에 시험 운영하고, 2027년부터 본격적으로 쓴다.

## 화면

- 💳 월 예산 잔액, ☀️ 오늘 쓸 수 있는 돈, 💵 이번 달 수입 · 💸 지출 · 🐷 모은 돈 (지난달과 비교)
- 🧾 분야별 지출(비율·건수), ✂️ 앞으로 줄일 수 있는 돈(꼭 필요하지 않았던 지출 + 월말 예상 지출)
- 📈 월별 수입·지출 꺾은선(2027년 1월부터, 그 해 1~12월), 📉 주별 지출 꺾은선(최근 8주, 주간 예산선), 📅 일별 지출, 📒 통장식 거래내역

## 연습 기간과 2027년 시작

- 2026/12/31까지는 연습 기간이다. 화면 위에 🧪 안내가 뜨고, 월별 그래프 대신 주별 그래프로 확인한다.
- 2027년에 처음 앱을 열면 2026년 기록과 예산이 자동으로 정리된다. 지우기 전에 사본(`fee.practice`)을 따로 보관하고, 🎉 안내의 **연습 기록 파일로 받기**로 내려받을 수 있다.

## 이렇게 쓰기

- **매달 1일:** 통장 카드의 **예산 설정**에서 이번 달 생활비를 정한다. (11월은 11/13~11/30분만)
- **돈을 쓴 직후 (10초):** 금액과 분류를 넣고 **거래 기록**을 누른다. 사고 싶어서 산 것이면 "꼭 필요한 지출이었어요" 체크를 끈다.
- **매일:** **오늘 쓸 수 있는 돈** 안에서만 쓴다. 남은 예산을 남은 날수로 나눈 금액이라 아낀 날이 있으면 다음 날 한도가 늘어난다.
- **일요일 밤 (3분):** 일별 지출에서 빨간 막대(하루 예산 초과)가 몰린 요일을 찾는다. **안 써도 됐던 지출** 금액을 다음 주에 줄일 목표로 삼는다. 백업 파일도 저장한다.
- **잘못 적었으면:** 거래내역의 ✎를 눌러 고치고 **수정 저장**을 누른다. ✕는 삭제다.
- **수입(알바비 등):** 입금으로 기록한다. 수입은 예산을 늘리지 않고 따로 집계되므로 "수입 − 지출"이 그달에 모은 돈이다.

## 데이터 저장 방식

DB를 쓰지 않고 **이 브라우저(localStorage)** 에 저장한다. 같은 기기의 같은 브라우저에서는 창을 닫아도 계속 남는다.

- 폰과 PC 사이에는 동기화되지 않는다. 주로 쓸 기기를 하나 정해서 쓴다.
- 브라우저의 사이트 데이터를 지우면 기록도 함께 사라진다. 시크릿 모드에서는 저장되지 않는다.
- 매달 처음 열 때 백업 알림이 뜬다. **지금 백업 저장**을 한 번 눌러 둔다. 언제든 **백업 파일 저장** 버튼으로도 저장할 수 있다. 기기를 바꿀 때는 새 기기에서 **백업 불러오기**를 하면 된다.
